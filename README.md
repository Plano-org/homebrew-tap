# Plano for Homebrew

This tap installs [Plano](https://plano.sh), a planning tool for macOS where you plan with agents in a shared document instead of a chat. Plano needs macOS 13 or later.

## Install

```bash
brew install --cask plano-org/tap/plano
```

## Update

```bash
brew upgrade --cask plano
```

The app also checks for updates on its own.

## Uninstall

```bash
brew uninstall --cask plano
```

## Releases

Release notes and DMGs are in [plano-org/releases](https://github.com/plano-org/releases). The release job rewrites `Casks/plano.rb` on each release, so don't edit it by hand.
